# Store and Profile Guide

## 1. Two different things

| Area | What it controls |
|------|------------------|
| **Your profile** | Your personal login, password, 2FA |
| **Store settings** | The shop identity buyers see (name, logo, formats, social) |
| **Plan & Billing** | Your company’s subscription to Buyience |

---

## 2. Update your profile and security

**Where:** Settings → Account → **Profile & Security** (Account Settings page)

### Steps

1. Open **Profile & Security**.  
2. Update personal information fields.  
3. Save changes.  
4. To change password: enter current and new password → Save.  
5. To enable 2FA: start setup → scan QR → enter verification code → store recovery codes safely.

**Expected result:** Next login uses the new password/2FA settings.

**Mistake:** Saving recovery codes only on the same laptop you might lose.

---

## 3. Store Settings

**Where:** Settings → Store Management → **Store Settings**

### Tabs

| Tab | What you set |
|-----|----------------|
| **Store Details** | Store information (name, contact, basic identity) |
| **Regional & Formatting** | Locale-style formats for the store |
| **Social Media** | Social links (TikTok, Pinterest, Snapchat, Discord show **Coming Soon**) |
| **Branding** | Logo and favicon |

### How to update store details

1. Open **Store Settings**.  
2. Choose the tab you need.  
3. Edit the fields.  
4. Save (use the save control on that screen).  

**Result:** Storefront branding and details update for your shop.

**Currency note:** Some currency UI may show a **Coming Soon** overlay — if you cannot edit currency freely, contact Buyience support or your admin.

---

## 4. Other storefront controls (admin)

| Setting | Purpose |
|---------|---------|
| **Menu** | Navigation structure on the storefront |
| **Store Pages** | Pages / homepage sections |
| **Theme & Appearance** | Visual style |
| **Website Sliders** | Banners/sliders |
| **Email Templates** | Automated store emails |
| **Notifications** | Notification preferences |

**How to use (general):**

1. Open the setting from Store Management.  
2. Create or edit the item.  
3. Save.  
4. Preview on the storefront if a preview/live link is available.

---

## 5. Business operations that affect selling

Under Settings → Business Operations (as permitted):

| Area | Why it matters |
|------|----------------|
| Markets | Where/how you sell |
| Payment Methods | How buyers pay |
| Payment Terms | B2B due dates / terms |
| Quote Settings | Quote behaviour |
| Tax | Tax calculation |
| Shipping | Delivery zones and rates |
| Pricing Visibility | Who can see prices/stock |
| Floor Margin | Blocks or routes prices that are too low |

Change these carefully — they affect live quotes and checkout.

## 6. How this connects to websites

|--------|----------------------------|-----------------|

## 7. Benefits

- Consistent brand for buyers.  
- Correct formats for dates/numbers/currency displays.  
- Secure personal access with 2FA.  
- Clear separation between “my login” and “the shop”.
