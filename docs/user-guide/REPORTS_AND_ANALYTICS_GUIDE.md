# Reports and Analytics Guide

## 1. What reporting exists?

Buyience provides **dashboard screens** with live operational metrics. These are not a separate BI tool, but they are enough for daily management.

---

## 2. Main Dashboard

**Where:** Left menu → **Dashboard**

### What you typically see

- Total revenue (summary)  
- Active quotes  
- Customer counts  
- Recent orders  
- Quote engine status  
- Top customers / products (as shown)  
- Inventory alerts  

### How to use it

1. Open **Dashboard** each morning.  
2. Note any red/urgent alerts (stock or failed items).  
3. Click through to Orders, Quotes, or Inventory to act.  

**Benefit:** One screen for “what needs me today?”

---

## 3. Demo / Platform Dashboard

**Where:** **Demo Dashboard** (platform analytics)

Broader analytics: revenue, operations, performance, inventory alerts.

Use it when you need a wider performance view than the main ecommerce home.

---

## 4. Sales Dashboard

**Where:** **Sales Dashboard** (if listed for your user)

Sales-style metrics such as revenue, conversion, win rate, and forecasts (presentation can be demo/CRM flavoured).

Use filters/date controls **if shown on screen**. If a control is missing, the metric is a fixed snapshot for that view.

---

## 5. Prame Ai home

**Where:** **Prame Ai**

An AI-oriented home with shortcuts and activity-style widgets (beta). Use it as a launch pad, not as your only source of financial truth.

---

## 6. Module-level analytics

Many lists include analytics widgets or summary cards (products, orders, customers) depending on permission.

**How to use:**

1. Open the module (e.g. Products, Orders).  
2. Read the summary cards at the top if present.  
3. Use list filters to narrow the dataset.

---

## 7. Coming Soon Features page

**Where:** **Coming Soon Features**

This shows **roadmap** cards (for example bulk tools or advanced finance). It is **not** a live report.

---

## 8. How to track product performance (practical)

1. Dashboard → note top products (if listed).  
2. Products list → sort/filter by activity if available.  
3. Orders → review which SKUs repeat.  
4. Inventory → check which items hit safety stock often.

---

## 9. Common mistakes

1. Treating demo/sales dashboards as audited accounting.  
2. Ignoring inventory alerts until stockouts happen.  
3. Comparing numbers across dashboards without matching date ranges.
