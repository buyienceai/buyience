# Seller / Store Operator User Guide

## Important clarification

Buyience does **not** provide a separate marketplace “Seller Centre” with vendor payouts and commissions.

In this product, a **seller** means:

- Your company selling to buyers, and  
- Team members who create quotes, take orders, and manage stock in the **same dashboard** as admins.

What you can do depends on the **role** your admin gave you.

---

## 1. How to access the dashboard

1. Open your store’s Buyience app login (for example **app.buyience.com**).
2. Sign in with your email and password.
3. Complete 2FA if prompted.
4. Use the left menu for Products, Orders, Quotes, Inventory, and Customers.

If a menu is missing, ask your admin for permission — this is normal, not a bug.

---

## 2. Your profile and account settings

**Where:** Settings → Account → **Profile & Security** (or Account Settings)

### What you can usually do

| Task | How |
|------|-----|
| Update your name / contact details | Profile & Security → edit fields → Save |
| Change password | Profile & Security → password section → Save |
| Turn on two-factor authentication | Follow 2FA setup (QR code → verify → keep recovery codes) |

### Business / store details

Store-wide information (logo, address, regional formats) is under **Store Settings**. You need Store Settings permission to change it. See [STORE_AND_PROFILE_GUIDE.md](./STORE_AND_PROFILE_GUIDE.md).

### Plan & Billing

Usually **admin-only**. This is your company’s Buyience subscription, not your personal earnings.

---

## 3. Your daily selling workflow

1. Open **Dashboard** — check new orders and quote activity.  
2. Open **Quote Engine** — answer open quotes and chats.  
3. Open **Orders** — move new orders through fulfilment.  
4. Open **Inventory** — fix low stock before promising delivery.  
5. Open **Products** — update prices or publish new items when needed.

---

## 4. Product management (seller)

Full detail → [PRODUCT_MANAGEMENT_GUIDE.md](./PRODUCT_MANAGEMENT_GUIDE.md)

**Short path to add a product:**

1. Go to **Products** → **All Products** (or Catalogue → Products → View All).  
2. Click **Create Product**.  
3. Complete tabs: **Basic** → (**Variants** if needed) → **Pricing** → **Inventory** → **Enrich**.  
4. Use **Save and Next** on each step.  
5. Click **Publish Product** when ready.

**Result:** A published product can appear on **your storefront**. It does **not** automatically become a page on the public buyience.com marketing website.

---

## 5. Order management (seller)

Full detail → [ORDER_MANAGEMENT_GUIDE.md](./ORDER_MANAGEMENT_GUIDE.md)

**Typical flow:**

1. **Orders** → **View All**.  
2. Open an order.  
3. Check customer, lines, and payment info.  
4. Use **Update Status** (for example New → In Progress → Shipped → Delivered).  
5. Add an internal note if needed (**Save Note**).  
6. Create shipping labels from **Shipping Labels** if you use that feature.  
7. Handle returns from **Returns** when buyers send items back.

---

## 6. Inventory (seller)

Full detail → [INVENTORY_MANAGEMENT_GUIDE.md](./INVENTORY_MANAGEMENT_GUIDE.md)

| Goal | Where |
|------|-------|
| See stock levels | Inventory → View All → Overview |
| Edit on-hand stock | Edit the stock fields → **Save** |
| Buy more stock | Purchase Orders → Add New PO |
| Move stock between locations | Transfer Order |
| Manage suppliers | Suppliers |

**When stock reaches zero:** The product can show as out of stock (when tracking is on). Do not promise delivery until stock is updated.

## 9. Benefits of using the seller workflows in Buyience

- One place for catalogue, quotes, and orders.  
- Fewer spreadsheet mistakes on price and stock.  
- Clear order statuses for the team.  
- Quote tools for negotiated B2B deals.  
- Permissions so junior staff cannot change critical settings.

---

## 10. Common seller mistakes

1. Publishing a product without category or price.  
2. Updating order status to Shipped before stock is reserved/picked.  
3. Turning off inventory tracking and then overselling.  
4. Expecting products to show on buyience.com marketing pages.  
5. Looking for a separate “seller payout” screen that does not exist.
