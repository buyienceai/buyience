# Button Cheat Sheet

**Last updated:** November 2026

Quick meanings for the buttons you use most. Full steps live in the linked guides.

---

## Products

| Button | Purpose | Typical result |
|--------|---------|----------------|
| **Create Product** | Start a new product | Opens Add New Product |
| **Save and Next** | Save current tab and continue | Unlocks the next tab |
| **Publish Product** | Make the product live | Status becomes Published |
| **Update** | Save edits | Changes stored |
| **Save and Exit** | Save and leave the form | Returns to list |
| **View Live** | Open storefront view | Shop page (when available) |
| **Delete** | Remove product | Needs confirmation |
| **Generate Variants** | Build variant rows from attributes | Variant table fills |
| **Save Variants** | Store variant SKUs/status | Variants saved |
| **Browse Files** / **Media Library** | Attach images/video | Media added |
| **Add Price Tier** | Add volume pricing row | New tier line |

## Safety tips

1. Prefer **Update Status** over guessing — wrong “Shipped” confuses the whole team.  
2. **Delete** and **Revoke** usually need a good reason; confirm before clicking.  
3. **Archive** is often reversible with **Restore**; **Delete** may not be.  
4. If a button is missing, you likely lack permission — ask your admin.
