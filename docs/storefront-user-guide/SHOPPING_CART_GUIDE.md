# Shopping Cart Guide

**Last updated:** November 2026

## 1. What is the shopping cart?

It lists products you plan to buy, with quantities, discounts or BOGO offers (when your store runs them), and the path to checkout.

**Page title:** **Shopping Cart (n items)**  
**Breadcrumb:** **Continue Shopping** / **Shopping Cart**

**Where to find it:** Click the **cart** icon in the header.

---

## 2. How to use the cart (step by step)

1. Open the cart icon.
2. Review each line (image, name, options, price when visible).
3. Change quantity with + / −, or remove a line with the delete control.
4. Use extra actions when you need them:

| Control | Purpose |
|---------|---------|
| **Continue Shopping** | Return to browsing |
| **Saved lists** → **Save cart to list** | Save this cart as a list |
| **Saved lists** → **Import list to cart** | Load a saved list into the cart |
| **Add products** → **Quick order** | Add products quickly |
| **Add products** → **Bulk order** | Bulk add (when your role allows it) |
| **Export** → **Export as CSV** | Download the cart as CSV |
| **Export** → **Export as PDF** / **Export as PDF (images)** | Download a PDF |
| **Proceed to Checkout** | Start checkout |
| **Request Quote Instead** | Build a quote instead of buying now (when shown) |

5. Check **Order Summary**: **Subtotal**, **Discount**, **Total** (or **Price on Request** if prices are hidden).
6. If a BOGO offer appears, follow the banner or drawer to pick reward items.

---

## 3. Empty cart

Use **Continue Shopping** or **Import from list** (when offered) to add products.

---

## 4. Expected result

Cart totals update. **Proceed to Checkout** opens checkout for your store type.
