# Order Management Guide

**Last updated:** November 2026

## 1. What is order management (buyer)?

The **Orders** area of your buyer **Dashboard** — list and detail screens for purchases you placed with this store.

**Why you need it:** Track status, pay when needed, cancel or re-order when allowed, and start returns.

**Where to find it:** Header → **Dashboard** → **Orders**.

Intro text on the list: **Track and manage your purchase orders**.

**Note:** **Orders** means your shop purchases. The separate sidebar item **Purchase Orders** is often **Coming Soon** and is not the same screen.

---

## 2. Orders list (step by step)

1. Sign in and open **Dashboard** → **Orders**.  
2. Use status filters (including **Cancelled** and other statuses shown).  
3. Use download/export on the toolbar when available.  
4. Open an order with the view (eye) control, or click through to order details.

### Actions on the list

| Action | Purpose |
|--------|---------|
| View (eye) | Open order details |
| **Pay** | Retry or complete payment when the order is unpaid (not for COD) |

A violet **Reorder** badge may appear on an order number when that order was created by re-ordering — it is a label, not a button.

Shipping badges may appear when the store uses shipment tracking.

---

## 3. Order detail

Open an order to review lines, totals, addresses, and status.

### Buttons you may see (when allowed)

| Button | Purpose |
|--------|---------|
| **Pay now** / **Pay now (optional)** / **Retry payment** | Complete or retry payment |
| **Download Invoice** / **Generating Invoice...** | Download the invoice PDF |
| **Track Package** / **Opening Tracking...** | Open shipment tracking |
| **Cancel Order** | Opens **Cancel Order** — enter a reason, then confirm (**Cancelling...**) |
| **Re-order** | Start a new order from these lines |
| **Request Return** | Start a return (**Return More Items** if a return already exists) |

Returns continue under **Dashboard** → **Returns**. Invoices may also appear under **Dashboard** → **Invoices**.

---

## 4. After checkout

The success screen may show **Order Placed Successfully!** with **View Orders** or **Continue Shopping**.

---

## 5. Expected result

You can find an order, understand its status, pay if needed, and use **Cancel Order**, **Re-order**, or **Request Return** when those buttons appear on the detail page.
