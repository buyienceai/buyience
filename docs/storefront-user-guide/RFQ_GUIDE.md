# Request Quote Guide

**Last updated:** November 2026

## 1. What is Request Quote?

Request Quote (RFQ) lets you ask for negotiated pricing instead of (or before) buying from the cart. It is common on B2B stores.

**Why you need it:** Many wholesale deals start with a quote, not an immediate checkout.

**Where to find it:**

- Product cards / product page → **Request Quote**  
- Header quote icon → **Request for Quote**  
- Cart → **Request Quote Instead** (when shown)  
- **Dashboard** → **Create Quote**, or **Quotes** to manage existing quotes  

---

## 2. Add products to a quote

1. On a product card or product page, click **Request Quote** (or wait through **Requesting...**).  
2. The button may change to **In RFQ** / **View RFQ**.  
3. Open **Request for Quote** from the header icon to review the list.

---

## 3. Request for Quote cart

Page title: **Request for Quote**.

| Control | Purpose |
|---------|---------|
| Empty state | **Your RFQ Cart is Empty** |
| **Add Products** | Add more catalogue items |
| **Import from list** / **Import list to RFQ** | Import a saved list |
| **Quick Quote - Add Multiple Products** | Add several items at once |
| **Generate AI Quote** | Only when your store enables AI quoting |
| Price columns | List / Your / Proposed prices as shown |
| **Submit Quote Request** / **Continue to Submit RFQ** | Start the submit steps |
| **Sign Up to View Pricing** | Pricing needs an account |

---

## 4. Submit steps

1. **RFQ Details**  
2. **Contact Information**  
3. **Delivery Requirements**  
4. **Review**  

Complete each step, then confirm. The success screen shows confirmation, PDF options, and **Quick Actions** when available.

Guest quote and invitation links may be offered by your supplier when they share them — follow the on-screen form.

---

## 5. Manage quotes in the Dashboard

1. Open **Dashboard** → **Quotes**.  
2. Open a quote to see status and details (including negotiation chat when available).  
3. When a quote is accepted, follow on-screen actions to place an order if offered.

Typical stages: submitted → negotiation → approved or rejected → may convert to an order.

---

## 6. Expected result

Your quote request is submitted and appears under **Quotes** for follow-up with the seller.
